## [Hallucinate Then Match: A Clever Tagging Technique for Large LLM Vocabularies](https://simonwillison.net/2026/Aug/14/dont-classify-hallucinate/) ⭐️ 7.0/10

Doug Turnbull developed a technique where LLMs generate novel tags without seeing the existing vocabulary, then vector embeddings are used to map those hallucinated tags to the closest real ones. This approach was highlighted by Simon Willison as a solution for handling large tag collections like his 1,856 blog tags. This technique provides a practical workaround for the token limit problem in LLM classification tasks, enabling systems to handle vocabularies far larger than what can fit in a single prompt. It opens up new possibilities for tagging, categorization, and information retrieval at scale. The approach uses a prompt that instructs the model to create novel classifications based on example tag formats, then relies on vector embeddings to find the nearest matches in the existing corpus rather than forcing the model to choose from a massive predefined list.

rss · Simon Willison · Aug 14, 21:54

**Background**: Vector embeddings transform data points like words or sentences into n-dimensional arrays that capture their semantic characteristics, allowing machines to compare and classify data efficiently. LLMs typically face token limits that restrict how much context they can process in a single prompt, making it challenging to feed large vocabularies for classification tasks. This technique cleverly sidesteps that limitation by having the model generate plausible tags first, then using embeddings to find real-world equivalents.
