A GitHub project called vphone-cli enables booting a virtual iPhone on Apple Silicon Macs using Apple's Virtualization.framework, providing a hardware‑virtualized iOS environment rather than an emulator or simulator. This tool offers a practical way to run actual iOS code on a Mac for security research and development without jailbreaking, bridging the gap between the iOS Simulator (which runs x86 code) and physical devices. The project requires disabling or partially disabling System Integrity Protection (SIP) during setup, and users must avoid selecting Japan or the EU as the region to bypass regulatory checks that the VM cannot satisfy.

hackernews · hentrep · Aug 28, 23:02 · [Discussion](https://news.ycombinator.com/item?id=49485267)

**Background**: Apple's Virtualization.framework, introduced in macOS Big Sur, allows creating virtual machines on Apple Silicon and Intel Macs using hardware virtualization, so the guest kernel executes native ARM64 instructions at near‑native speed. Unlike the iOS Simulator, which recompiles apps for x86, this approach runs the actual iOS binary, making it valuable for security research and testing.
