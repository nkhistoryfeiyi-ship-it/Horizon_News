## [Kakehashi：在 Linux ARM 上运行 macOS 二进制文件的实验性用户态项目](https://github.com/wie-project/kakehashi) ⭐️ 6.0/10

Kakehashi 是一个实验性用户态项目，能够在 Linux ARM 系统上运行 macOS CLI 二进制文件。目前已有 7-Zip 的工作原型（通过多线程压缩测试，比原生慢约 5.2 倍）和 curl 的工作原型（超过 200 个命令和选项通过自动化 Docker 测试）。 该项目代表了在 Linux ARM 上运行 macOS 应用程序的进展，类似于 WINE/Proton 如何让 Windows 应用程序在 Linux 上运行。它可能有助于需要在 ARM Linux 系统上使用 macOS 工具的开发者用户。 该项目采用用户态方法而非完整模拟，7-Zip 目前运行速度比原生 Linux 慢约 5.2 倍。开发者已制定了明确的优化计划来缩小这一性能差距。

hackernews · vlad_kalinkin · 8月2日 16:26 · [社区讨论](https://news.ycombinator.com/item?id=49145937)

**背景**: Darling 是一个开源的 macOS 兼容性层，为 Linux 提供 macOS 库和框架的替代实现，常被称为 macOS 应用的 WINE。与在虚拟机中运行 Apple 专有操作系统的模拟不同，Darling 在用户态将 macOS 系统调用转换为 Linux 等效调用。
