## [Realta Fusion 声称首次直接从等离子体产生电力](https://techcrunch.com/2026/06/30/realta-fusion-generates-electricity-directly-from-a-fusion-reaction-an-apparent-first/) ⭐️ 9.0/10

由威斯康星大学麦迪逊分校研究支持的初创公司 Realta Fusion 声称，他们首次实现了从聚变反应等离子体直接发电。首席执行官基兰·弗隆表示，他们可以直接从等离子体中提取电力，这标志着展示该技术可能性的一个重要里程碑。 这一成就通过绕过与蒸汽轮机相关的传统热转换低效率问题，代表了聚变能源领域的潜在范式转变。如果得到验证，直接能量转换可以通过回收输入电力并消除对冷却塔的需求，显著提高聚变电站的经济可行性和可扩展性。 该公司利用磁喷嘴技术方法，建立在威斯康星高温超导轴对称实验（WHAM）装置的工作基础之上，该装置实现了高磁场。这种方法不同于传统的磁约束聚变，它侧重于直接捕获带电粒子，而不是加热水来驱动涡轮机。

rss · TechCrunch · 6月30日 19:12

**背景**: 传统的聚变反应堆通常依靠磁约束来容纳等离子体，其中产生的热量用于加热水并驱动蒸汽轮机，类似于核裂变发电厂。直接能量转换是一个较老的概念，试图使用电场直接捕获带电聚变产物的动能，有可能在不使用机械运动部件的情况下提供更高的效率。Realta Fusion 的声明表明，他们使用先进的高温超导磁体成功应用了这一原理。

## [Claude Code 通过提示词隐写术嵌入隐藏元数据](https://thereallo.dev/blog/claude-code-prompt-steganography) ⭐️ 8.0/10

分析显示，Claude Code 使用提示词隐写术，根据用户的 API 基础 URL 和时区在 API 请求中嵌入隐藏标记。这种技术使 Anthropic 能够追踪使用模式并识别特定实体（例如可能进行模型蒸馏的中国公司），而无需明确通知用户。 这种做法引发了关于透明度和用户信任的重大担忧，因为它涉及在主要 AI 开发工具中进行隐蔽的数据传输。它突显了提供商运营需求与用户对用户数据和交互处理方式拥有完全可见性期望之间的紧张关系。 这些标记嵌入在系统提示词中，因此在正常操作期间对模型和用户不可见。批评者指出，该实现看起来粗糙且容易通过逆向工程检测，表明缺乏复杂的混淆技术。

hackernews · kirushik · 6月30日 15:44 · [社区讨论](https://news.ycombinator.com/item?id=48734373)

**背景**: 隐写术是一种将信息隐藏在非秘密数据中的做法，例如图像、音频文件，或在本案中，文本提示词。在 AI API 的背景下，在提示词中嵌入元数据允许提供商对请求进行指纹识别或追踪使用情况，而不改变用户输入的语义含义，从而为遥测数据创建了一条隐蔽通道。
