## [谷歌从 Chrome 应用商店移除 MV2 扩展，包括 uBlock Origin](https://webiterate.dev/google-removed-extensions-ublock-origin-108/) ⭐️ 7.0/10

谷歌已从 Chrome 应用商店移除 Manifest V2 扩展，包括流行的广告拦截器 uBlock Origin，这是其淘汰旧扩展框架计划的一部分。最终移除定于 2026 年 8 月 31 日，Chrome 151（2026 年 7 月 28 日稳定版）删除了允许重新启用 MV2 的最后开发者标志。 此举对依赖广告拦截器和 MV2 扩展的数百万 Chrome 用户产生重大影响，引发了人们对谷歌对浏览器生态系统的控制以及网络广告拦截未来的担忧。这也凸显了向 Manifest V3 的转变，该版本限制了广告拦截功能，迫使用户寻求 Firefox 或 Edge 等替代方案。 Manifest V2 允许扩展直接访问网络流量以进行实时过滤，而 MV3 通过服务工作者和远程规则列表限制此功能，削弱了 uBlock Origin 等广告拦截器的效果。Chrome 在 2025 年移除了重新启用 MV2 的能力，最后一个开发者标志在 Chrome 151 中被删除，使得恢复 MV2 支持的机制不复存在。

**背景**: 浏览器扩展是增强浏览器功能的小型软件程序。Manifest V2 和 V3 是 Chrome 及其他 Chromium 浏览器使用的扩展框架的两个版本。MV2 于 2010 年推出，赋予扩展广泛的权限，尤其是广告拦截功能；MV3 于 2020 年宣布，重构了架构以提升安全性和隐私性，但限制了实时网络访问。

## [互联网中心化与 NAT 的原罪](https://dreamstation.systems/personal/ntppost.html) ⭐️ 7.0/10

文章认为 NAT 是导致互联网中心化的最早因素，使得运行个人服务器变得困难，并推动架构向客户端-服务器模式转变。 这一分析揭示了为 IPv4 耗尽而设计的解决方案如何无意中塑造了现代互联网架构，有利于集中式服务并使点对点通信复杂化。 Linux 中 NAT 的实现者 Rusty Russell 指出，避免端口保留而倾向于将更多连接压缩到一个 IP 地址，意味着来自不同地址的入站流量变得不可路由，削弱了托管公共端点的能力。

hackernews · robinpie · 8月31日 02:23 · [社区讨论](https://news.ycombinator.com/item?id=49504905)

**背景**: 网络地址转换（NAT）允许私有网络中的多个设备共享一个公共 IPv4 地址，在 IPv4 地址耗尽时变得至关重要。这项技术无意中鼓励了集中式架构，因为 NAT 后的设备在没有端口转发的情况下难以接收入站连接。

## [介绍 wrapture：Python 的统一测试与追踪工具](https://simonwillison.net/2026/Aug/31/introducing-wrapture/) ⭐️ 7.0/10

Graham Dumpleton 发布了 wrapture，这是一个新的 Python 库，扩展了 wrapt 的猴子补丁功能，实现了对函数和方法的统一测试与追踪。该库可作为 unittest.mock 的替代方案，并提供 OpenTelemetry 支持及基于配置文件的追踪机制。 这解决了 Python 开发中的一个常见痛点——观察和测试不受控制的代码——通过将测试和追踪功能整合到一个工具中。它可以在不修改代码的情况下简化现有 Python 项目的可观测性和单元测试工作流。 Wrapture 包含 OpenTelemetry 支持以及基于 TOML 的配置机制，可为现有项目添加追踪功能。值得注意的是，所有代码和文档均由 AI 助手在 Graham 的仔细指导下编写，他将其与'随意编码'区分开来。

rss · Simon Willison · 8月31日 23:59

**背景**: 猴子补丁是 Python 中的一种技术，允许在运行时修改已定义的模块或类中的函数、方法或属性，通常用于在不更改原始源代码的情况下为现有实现添加行为。Graham Dumpleton 开发的 wrapt 库为 Python 提供透明的对象代理，作为函数包装器和装饰器的基础，注重正确性。unittest.mock 是 Python 标准库中用于在测试期间模拟和修补对象的模块。
