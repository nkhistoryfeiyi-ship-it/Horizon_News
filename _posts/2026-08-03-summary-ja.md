## [Show HN: Kakehashi – Experimental userspace to run macOS binaries on Linux ARM](https://github.com/wie-project/kakehashi) ⭐️ 6.0/10

Kakehashi is an experimental userspace project that enables macOS CLI binaries to run on Linux ARM systems. It currently has working prototypes for 7-Zip (passing multi-threaded compression tests, ~5.2x slower than native) and curl (over 200 commands and options passing automated Docker tests). This project represents progress toward running macOS applications on Linux ARM, similar to how WINE/Proton enabled Windows applications on Linux. It could benefit developers and users who need macOS tools on ARM-based Linux systems. The project uses a userspace approach rather than full emulation, with 7-Zip currently running ~5.2x slower than native Linux execution. The developer has outlined a clear optimization plan to reduce this performance gap.

**Background**: Darling is an open-source macOS compatibility layer for Linux that provides alternative implementations of macOS libraries and frameworks, often called the counterpart to WINE for macOS apps. Unlike emulation that runs programs on Apple's proprietary OS in a virtual machine, Darling translates macOS system calls to Linux equivalents at the userspace level.
