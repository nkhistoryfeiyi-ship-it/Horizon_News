Graham Dumpleton has introduced wrapture, a new Python library that extends the monkeypatching capabilities of wrapt to enable unified testing and tracing of functions and methods. The library acts as an alternative to unittest.mock and provides OpenTelemetry support with a configuration-based mechanism for adding tracing to existing Python projects. This addresses a common pain point in Python development—observing and testing code you do not control—by combining testing and tracing into a single tool. It could simplify observability and unit testing workflows in existing Python projects without requiring code changes. Wrapture includes OpenTelemetry support and a TOML-based configuration mechanism for adding tracing to existing projects. Notably, every line of code and documentation was written by an AI assistant under Graham's careful direction, which he distinguishes from 'vibe coding.'

rss · Simon Willison · Aug 31, 23:59

**Background**: Monkey patching is a technique in Python where you modify functions, methods, or attributes on modules or classes at runtime after they have already been defined, typically to add behavior around an existing implementation without changing the original source. The wrapt library, also by Graham Dumpleton, provides transparent object proxies for Python that serve as the basis for function wrappers and decorators, with a strong focus on correctness. unittest.mock is Python's standard library module for mocking and patching objects during testing.
