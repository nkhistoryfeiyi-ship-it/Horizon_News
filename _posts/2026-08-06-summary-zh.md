## [Celld：自托管分布式持久对象](https://github.com/denoland/celld) ⭐️ 7.0/10

Celld 是 Cloudflare 持久对象的自托管分布式实现，使用基于 S3 兼容存储的每对象 SQLite 数据库，在 Cloudflare 平台之外复制有状态计算抽象。 这一发展对边缘计算生态系统意义重大，因为它提供了 Cloudflare 专有持久对象的替代方案，使开发者能够在去中心化节点上运行有状态的服务端 less 应用程序，同时保持供应商独立性。 每个持久对象都实现为通过名称寻址的独立 SQLite 数据库，并复制到用户拥有的 S3 兼容存储桶中。该项目来自 Deno Land，由于对 AI 生成的低上下文贡献的担忧，拉取请求目前已被禁用。

hackernews · calvinfo · 8月5日 16:50 · [社区讨论](https://news.ycombinator.com/item?id=49185430)

**背景**: Cloudflare 持久对象提供具有持久存储的全局唯一单线程计算实例，支持 AI 代理、实时聊天和协作应用等有状态服务端 less 应用程序。S3 兼容存储是指实现 Amazon S3 API 的对象存储服务，允许用户使用各种存储提供商同时保持 API 兼容性。
