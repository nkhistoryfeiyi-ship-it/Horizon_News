## [AMD 收购 Taalas，将 AI 模型直接蚀刻到硅片上](https://www.theregister.com/systems/2026/08/06/amd-acquires-ai-chip-startup-taalas-to-boost-inference-performance-by-etching-models-into-silicon/5284344) ⭐️ 8.0/10

AMD 已收购 Taalas，这是一家通过其 Foundry 平台将 AI 模型转化为称为“硬核模型”的定制硅片的初创公司，相比软件版本可实现高达 1000 倍的效率提升。此次收购旨在通过将模型直接集成到硬件中来提升 AMD 的 AI 推理性能。 此举使 AMD 能够通过提供专用硅片在 AI 推理市场中更具竞争力，类似于谷歌的 TPU 策略。随着 AI 推理需求呈指数级增长，定制硅片可能成为云服务提供商和企业寻求更低延迟和更低功耗的关键差异化因素。 Taalas 的 Foundry 平台将 AI 模型本身视为计算架构，取代了通用处理器的执行。他们的演示展示了一家 24 人初创公司以每秒 17,000 个 token 的速度运行 Llama 3.1 8B，社区成员指出推理和工具使用生成随每秒 token 数扩展。

hackernews · itvision · 8月6日 20:23 · [社区讨论](https://news.ycombinator.com/item?id=49201970)

**背景**: AI 推理是运行已训练的机器学习模型以生成预测或响应的过程，与构建模型的训练不同。虽然 GPU 擅长并行计算以进行训练，但由于其通用架构，在推理时可能效率低下。像 Taalas 这样的定制硅片专门为模型的架构优化硬件，从而降低延迟、功耗和每次推理的成本。

## [Datasette 1.0a38 修复混合表设置中的 SQL 注入漏洞](https://simonwillison.net/2026/Aug/6/datasette/#atom-everything) ⭐️ 8.0/10

Datasette 1.0a38 已发布，修复了一个 SQL 注入漏洞，该漏洞可能允许访问公开表的用户读取同一数据库中私有表的数据。此修复也已向后移植到 Datasette 0.65.3。 这很重要，因为它解决了 Datasette 权限系统中的安全缺陷，即 execute-sql 权限可能通过 SQL 注入被绕过，从而可能暴露敏感的私有数据。虽然受影响的配置——在同一数据库中同时提供公开和私有表——可能很少见，但对于使用它的任何实例来说都存在严重风险。 该漏洞特别影响在同一数据库中使用 Datasette 权限系统混合公开和私有表的实例。建议管理员在包含私有表的数据库上禁用 execute-sql 权限作为缓解措施，因为该漏洞在存在此限制的情况下仍允许只读访问私有表。

rss · Simon Willison · 8月6日 18:24

**背景**: Datasette 是由 Simon Willison 创建的用于探索和发布数据的开源工具。它允许用户处理各种形式的数据，进行分析探索，并以交互式网站和配套 API 的形式发布。该工具包含一个权限系统，可以限制对特定表的访问，但此漏洞表明 execute-sql 功能可能通过 SQL 注入绕过这些表级限制。
