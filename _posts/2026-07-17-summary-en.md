## [Puter Compiles Full Firefox Browser to WebAssembly](https://simonwillison.net/2026/Jul/16/firefox-in-webassembly/#atom-everything) ⭐️ 8.0/10

Puter has successfully compiled the entire Firefox browser into WebAssembly, allowing it to run inside another browser via a WebSocket protocol. This technical achievement demonstrates a full browser-in-browser environment, utilizing a 233MB gecko.wasm file. This project highlights the growing capability of WebAssembly to host complex, full-stack applications directly in the browser. It showcases how cloud desktop infrastructure can leverage AI-assisted compilation to create portable, web-native computing environments. The team selected Firefox due to its strong single-process support and used approximately $25,000 worth of AI tokens for the compilation process. Network traffic is proxied through Puter's servers using the low-overhead Wisp protocol to bypass browser security restrictions on direct network connections.

rss · Simon Willison · Jul 16, 23:34

**Background**: WebAssembly (Wasm) is a binary instruction format for a stack-based virtual machine, designed as a portable compilation target for programming languages, enabling deployment on the web for client and server applications. The Wisp protocol is a low-overhead method for proxying multiple TCP and UDP sockets over a single WebSocket connection, which is essential since browsers cannot open arbitrary network connections from sandboxed code. Puter is an open-source internet operating system that provides a cloud desktop environment, offering features similar to Google Drive but with full self-hosting capabilities.
