## [恶意 Rust crate Arrayref 执行构建时载荷](https://safedep.io/arrayref-proc-macro1-rust-build-time-malware/) ⭐️ 9.0/10

发现恶意 Rust crate Arrayref 通过其 proc-macro1 依赖项执行构建时载荷，促使 Rust 官方博客发布安全公告并从 crates.io 移除受影响版本。 此事件凸显了开源供应链中的关键漏洞，因为构建脚本以开发者权限执行，可在编译过程中窃取凭证、源代码和签名密钥。 载荷嵌入在 proc-macro1 1.0.107 版本中，该版本将命令与控制地址存储为 base64 片段并在构建时重新组装；crates.io 随后移除了恶意发布版本，但未发布正式安全公告。

hackernews · abhisek · 8月20日 13:23 · [社区讨论](https://news.ycombinator.com/item?id=49374269)

**背景**: Rust 构建脚本（build.rs）在包编译期间运行，可完全访问开发者的环境，包括密钥和源代码。针对开源依赖项的供应链攻击通常涉及毒害广泛使用的 crate，以破坏下游项目，而 Rust 和 JavaScript 等语言中常见的庞大依赖树加剧了这一风险。

## [Bun 1.4 发布：引入 WebView API 与重大性能提升](https://simonwillison.net/2026/Aug/20/bun-webview-json-api/) ⭐️ 8.0/10

Bun 1.4 作为 Rust 重写后的首个稳定版本正式发布，引入了用于浏览器自动化的 Bun.WebView API，并带来了显著的性能提升，包括 CPU 使用量降低 5 倍和启动速度提升 50%。Simon Willison 通过构建一个类似 shot-scraper 的 JSON API 展示了该 WebView 功能的实际应用。 此次发布标志着 Bun 运行时的一个重要里程碑，证明 Rust 重写带来了显著的性能提升，同时通过原生浏览器自动化支持扩展了平台能力。新的 WebView API 可能通过为无头浏览器操作提供 Puppeteer 和 Playwright 的内置替代方案，对 JavaScript 生态系统产生重大影响。 Bun.WebView 支持 macOS WebKit（零外部依赖）和通过 Chrome DevTools Protocol 的 Chromium，Simon Willison 的原型仅需 192MB-256MB 内存即可在复杂网页上运行完整的 Chrome 实例。该版本还添加了超过 1,500 个来自 Node.js 测试套件的测试，标志着自 Bun 1.0 以来 Node.js 兼容性最大的提升。

rss · Simon Willison · 8月20日 15:37

**背景**: Bun 是一个用 Rust 编写的快速 JavaScript 运行时和工具包，旨在作为 Node.js 的即插即用替代品，具有更快的启动时间和更低的内存使用。shot-scraper 是 Simon Willison 开发的 CLI 工具，用于使用 JavaScript 拍摄网站截图和抓取内容，基于 Playwright 构建。Puppeteer 和 Playwright 等浏览器自动化工具通常需要单独下载浏览器且资源消耗较大，这使得 Bun 内置的 WebView 成为一个潜在的轻量级替代方案。
