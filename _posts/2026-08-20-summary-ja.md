Go 1.27 has been released, introducing generic methods, post-quantum cryptography support via the mldsa package, improved floating-point parsing using Russ Cox's uscale algorithm, and a standardized uuid package. The release also includes a new JSON v2 implementation and faster small memory allocations. This major release significantly enhances Go's type system and security posture, impacting developers building systems that require modern cryptography or efficient generic code. The standardized uuid package is expected to drive widespread migration from third-party libraries, starting with major projects like Kubernetes. Generic methods allow type parameters on methods, enabling chainable pipelines previously impossible. The mldsa package implements NIST-standardized ML-DSA post-quantum signatures, with lead maintainer Filippo Valsorda urging prompt deployment. Floating-point parsing now uses the uscale algorithm for improved accuracy.
