## [可视化 Rust 的 Vtable：dyn Trait 在内存中的工作原理](https://sofiabelen.github.io/projects/visualizing-rusts-vtables-how-dyn-trait-works-in-memory/) ⭐️ 7.0/10

一篇文章通过 vtable 解释了 Rust 的 dyn trait 在内存中的工作原理，涵盖了动态分发机制和 vtable 指针机制。还讨论了零大小类型并与 C++ 的行为进行了比较。 理解 vtable 对于使用 trait 对象和动态分发的 Rust 开发者至关重要，因为它揭示了运行时多态的底层实现方式。这种知识帮助开发者在系统编程中做出关于性能和内存使用的明智决策。 vtable 指针仅在显式使用 &dyn Trait 或 Box 时出现。文章指出“对象安全性”已在最近的 Rust 文档中更名为“dyn 兼容性”。零大小类型（ZST）的处理方式与 C++ 不同，在 C++ 中每个对象必须至少占用 1 字节。

hackernews · torutofu · 9月5日 13:31 · [社区讨论](https://news.ycombinator.com/item?id=49576343)

**背景**: Rust 使用两种分发方式：泛型代码的静态分发（单态化）和 trait 对象的动态分发（vtable）。vtable 是一个包含函数指针的结构体，编译器为每个实现 trait 的具体类型自动生成。当你创建像 &dyn Trait 这样的 trait 对象时，编译器会创建一个包含数据指针和 vtable 指针的胖指针。

## [中德团队研制超灵敏'漂浮指南针'搜寻暗物质](https://www.scmp.com/news/china/science/article/3366481/chinese-german-team-builds-ultra-sensitive-floating-compass-hunt-dark-matter?utm_source=rss_feed) ⭐️ 7.0/10

中德研究团队研制出悬浮磁铁磁力计（LeMaMa），这是一种可在室温下运行的台式传感器，能够探测到飞特斯拉级别的磁场——约为地球磁场的十亿分之一。 这一进展大幅拓宽了对难以捉摸的暗物质粒子的搜寻能力，因为其假设的相互作用可能产生极其微弱的磁场信号。室温运行尤为引人注目，因为许多量子传感器需要昂贵的低温冷却。 LeMaMa 利用磁梯度场悬浮磁铁，并通过抗磁材料稳定其位置，以光学方式检测其运动。它通过利用铁磁体中的强自旋-晶格耦合来抑制自旋投影噪声，从而实现飞特斯拉级灵敏度。

rss · South China Morning Post · 9月5日 12:00

## [特斯拉 Cybercab 已部署，正接受联邦调查](https://arstechnica.com/cars/2026/09/teslas-cybercab-has-been-deployed-and-its-already-under-investigation/) ⭐️ 7.0/10
