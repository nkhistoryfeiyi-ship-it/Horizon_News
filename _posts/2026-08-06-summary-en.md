## [Celld: Self-hosted, Distributed Durable Objects](https://github.com/denoland/celld) ⭐️ 7.0/10

Celld is a self-hosted, distributed implementation of Cloudflare's Durable Objects, using per-object SQLite databases backed by S3-compatible storage to replicate the stateful compute abstraction outside of Cloudflare's platform. This development is significant for the edge computing ecosystem as it provides an alternative to Cloudflare's proprietary Durable Objects, enabling developers to run stateful serverless applications across decentralized nodes while maintaining vendor independence. Each durable object is implemented as its own SQLite database addressed by name and replicated to an S3-compatible bucket the user owns. The project comes from Deno Land (denoland), and pull requests are currently disabled due to concerns about AI-generated low-context contributions.

hackernews · calvinfo · Aug 5, 16:50 · [Discussion](https://news.ycombinator.com/item?id=49185430)

**Background**: Cloudflare Durable Objects provide globally unique, single-threaded compute instances with persistent storage, enabling stateful serverless applications like AI agents, real-time chat, and collaborative apps. S3-compatible storage refers to object storage services that implement the Amazon S3 API, allowing users to leverage various storage providers while maintaining API compatibility.

## [DeepMind Paper Argues LLMs Cannot Make Conceptual Leaps in Science](https://openreview.net/challenge?redirect=%2Fforum%3Fid%3DklU4737opt) ⭐️ 7.0/10

A DeepMind position paper by researcher Tom Zahavy argues that modern LLMs are structurally incapable of performing the abductive 'jump' from sensory experience to axioms, which the author considers critical for revolutionary scientific discovery. This paper directly challenges the optimistic narrative that LLMs could eventually replicate human scientific genius, framing a fundamental architectural limitation that could shape how the AI community approaches AI-assisted discovery. The paper contrasts induction (inferring general rules from observations) with abduction (the creative leap to new axioms), noting that while LLMs can perform induction, they lack the capacity for the abductive jump that characterized Einstein's work on special relativity.

hackernews · theanonymousone · Aug 5, 11:01 · [Discussion](https://news.ycombinator.com/item?id=49181083)

**Background**: Abductive reasoning, often called inference to the best explanation, is a form of logical reasoning that starts with an observation and seeks to find the simplest and most likely explanation. In the history of science, such leaps are associated with paradigm shifts, like Einstein's thought experiments that led to special relativity, which went beyond merely compressing existing data into a simpler theory.

## [The Valley of Webhooks: Reliability Problems and a Pull-Based Alternative](https://weli.dev/blog/the-valley-of-webhooks/) ⭐️ 7.0/10

A blog post analyzes the reliability problems of webhooks for state synchronization and proposes an alternative pull-based protocol called SCROLL that uses GET requests with headers instead of push-based notifications. Webhooks are widely used across APIs but suffer from reliability issues like deduplication, buffering, and bootstrap problems. This analysis and proposed alternative could influence how developers approach API integration and state synchronization in distributed systems. The SCROLL protocol requests subscriptions via GET with a Prefer: stream header, remarkably similar to the IETF draft Braid-HTTP Subscriptions. Key challenges addressed include signature verification, deduplication, buffering, bootstrap, and cron scheduling, though persistent connections may face CDN limits.

hackernews · weli · Aug 5, 15:22 · [Discussion](https://news.ycombinator.com/item?id=49184216)

**Background**: Webhooks are push-based notifications where servers send HTTP callbacks to clients when events occur. State synchronization ensures consistency across distributed systems. While webhooks provide real-time updates, they face reliability challenges including duplicate deliveries, missed events, and connection management issues that pull-based approaches can mitigate.
