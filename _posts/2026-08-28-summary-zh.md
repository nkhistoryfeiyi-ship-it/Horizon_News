## [Cloudflare 通过优化 1.1.1.1 DNS 缓存节省 100TB 内存](https://blog.cloudflare.com/dns-cache-memory-optimization-1111/) ⭐️ 7.0/10

Cloudflare 工程师优化了为 1.1.1.1 提供服务的 DNS 缓存，通过消除每个变体的枚举开销和装箱堆分配，并将数据紧凑打包，节省了 100TB 内存。 这项优化展示了低级系统编程在大规模应用中的实际影响，表明内存高效技术如何为公共 DNS 解析器等大规模基础设施带来巨大的成本节约。 该优化以随机索引换取顺序迭代，提高了 CPU 缓存局部性，但增加了 A/AAAA 记录轮询等功能的复杂性；不过，由于每条记录数量较小，成本可忽略不计。

hackernews · TangerineDream · 8月27日 17:17 · [社区讨论](https://news.ycombinator.com/item?id=49468083)

**背景**: 1.1.1.1 是 Cloudflare 的公共 DNS 解析器，提供快速且私密的互联网浏览服务。DNS（域名系统）是一个分布式层次系统，用于将域名转换为 IP 地址。DNS 缓存存储最近的查询结果以加速解析并减少上游查询。在 Cloudflare 的规模下，每个缓存条目的微小内存低效会因数百万条目而累积成 TB 级差异。

## [Experiential：开源 Rust LLM 网关，支持可选个性化模型训练](https://github.com/experientiallabs/experiential) ⭐️ 7.0/10

Experiential 是一个开源的 Rust 原生模型网关，可将自托管、前沿和开源模型统一管理，延迟低于 1 毫秒，并支持通过用户流量可选地训练个性化模型。它支持每日自动刷新 1000 多个模型，BYOK 请求的额外延迟低于 1 毫秒。 该项目通过提供零加价且具备独特模型训练能力的开源网关，满足了日益增长的 LLM 基础设施需求。它有望降低多模型供应商管理的技术门槛，同时引入了一种个性化的模型优化新方法。 该网关利用标准化的 OpenTelemetry 追踪来挖掘代表性任务，通过文本世界模型模拟推理过程，并在提示词嵌入上拟合最近邻分类器，从而为每个请求选择最优模型。它还基于模拟数据提供缓存命中优化和新模型建议。

hackernews · SilenN · 8月27日 21:18 · [社区讨论](https://news.ycombinator.com/item?id=49471407)
